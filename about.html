About the Project

Talaan is a CS 191 Software Engineering project developed by ACF for Solheim Library (UP School of Archaeology). This page keeps the project context, scope, roadmap, and team details in one place.

Project Background

The project is being prepared for Solheim Library (UP School of Archaeology) as part of CS 191. The final system name, detailed problem statement, and supporting project context are still to follow.

Project Goals

ACF aims to design and document a software solution that responds to the client's operational needs while meeting the course requirements for planning, analysis, design, implementation, and validation.

Scope

The project scope will be defined around Solheim Library's (UP School of Archaeology) confirmed requirements, the agreed deliverables for CS 191, and the features approved during planning.

Methodology

The team will keep a documented workflow through progress reports, project resources, and milestone updates. Requirements, design decisions, and implementation notes will be captured as the project develops.
