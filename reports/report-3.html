Prototype Completion and Online Deployment

Successfully completed and deployed the initial WebApp prototype through public hosting, including its user interface and database. The team is now focused on improving system features, developing user and staff functionalities, and preparing for client feedback and further testing.

Back to Timeline

Work Completed

  • Initial System Prototype: Successfully completed the initial working prototype of the WebApp, incorporating its user interface and database functionalities.
  • Online Deployment: Deployed the working prototype through public hosting, making both the user interface and database accessible online for demonstration and evaluation.

Work in Progress

  • Feature Improvements: Enhancing the existing system functionalities to improve usability and better address the client's requirements.
  • UI/UX Refinements: Keeping the interface open for revisions and improvements based on usability considerations and future client feedback.
  • User and Staff Database: Developing and refining database support for user and staff accounts, ensuring proper data organization and management.
  • User Profile Development: Developing the user profile section to allow users to view and manage their account information.
  • Staff Console Development: Developing a dedicated staff console to support staff-side operations and system management.

Upcoming Tasks

  • Client Prototype Presentation: Present the deployed working prototype to the client to demonstrate the current system functionalities and gather feedback for further improvements.
  • Feature Implementation: Continue developing and implementing the remaining system features based on the approved requirements and current prototype.
  • Database Population: Integrate actual library records into the database to support realistic system operations and demonstrate its intended functionality.
  • System Testing: Conduct testing of both user-facing and staff-facing functionalities to identify bugs, usability issues, and areas requiring improvement.
  • Documentation and Presentation Preparation: Update the system documentation to reflect implemented features, database changes, and development progress while preparing materials for upcoming project presentations.

Challenges/Risks

  • Academic Workload: Balancing project development activities with other academic requirements, which may affect the team's available time and productivity.
  • System Development: Translating the approved requirements and designs into a fully functional system while ensuring that the implementation aligns with the client's expectations.
  • Time Management: Ensuring that development, documentation, and client consultations are completed within the project timeline despite competing responsibilities and potential delays.
  • Corrupted Requirements Document: Recently discovering that the System Requirements Document is corrupted, potentially affecting the team's access to previously documented specifications and requiring recovery or reconstruction of the affected information.
