Requirements Approval and Initial Prototyping

Successfully completed and passed the WebApp Requirements Model and WebApp Architecture and Design. The team has begun developing the initial UI/UX prototypes, database schema, and working system prototype in preparation for client feedback and further development.

Back to Timeline

Work Completed

  • System Requirements Approval: Successfully presented and passed the WebApp Requirements Model, establishing the system's functional and non-functional requirements.
  • WebApp Architecture and Design: Successfully presented and passed the WebApp Architecture and Design, establishing the system's overall structure and design direction.
  • Initial UI/UX Prototyping: Started developing the initial user interface and user experience prototypes.
  • Database Schema: Started identifying the system's data entities and developing the preliminary database schema.

Work in Progress

  • UI/UX Prototyping: Developing the initial user interface and user experience prototypes to establish the system's layout, navigation, and overall usability.
  • Database Architecture: Continuing the design and development of the database schema to define the system's data entities and relationships.
  • Initial System Development: Developing the initial prototype system to establish the foundation for the software's core functionality.

Upcoming Tasks

  • Working Prototype Presentation: Prepare and present a functional initial system prototype to the client for feedback, evaluation, and suggestions for improvement.
  • Database Integration: Integrate actual data into the database to support the system's initial functionalities and demonstrate realistic use cases.
  • Client Consultation: Conduct another consultation with the client to discuss the prototype's progress, gather feedback, and clarify any remaining requirements.
  • Feature Documentation: Document the system's implemented and planned features, including their functionality and expected behavior.
  • Initial Testing: Test the prototype's existing functionalities to identify bugs, usability issues, and areas requiring improvement.
  • Prototype Refinement: Incorporate client feedback and make necessary adjustments to the system's interface and functionality.

Challenges/Risks

  • Academic Workload: Balancing project development activities with other academic requirements, which may affect the team's available time and productivity.
  • Prototype Development: Translating the approved requirements and designs into a functional working system while ensuring that the initial implementation aligns with the client's expectations.
  • Time Management: Ensuring that development, documentation, and client consultations are completed within the project timeline despite competing responsibilities and potential delays.
